Our research project was the analyse the replays of completed episodes from a Kaggle simulations competition. Replays are selected daily, ranked by average
agent rating, and capped at 20 GiB per day

The purpose was to chek how much the episodes are rated daily and how it affects the pokemon company.

The project followed the format of:
- data cleaning
- data anaysis
- data visualisation

The files included in the project are 
1. readme.md
2. dataset.csv
3. pokemon.json
4. docs.md
